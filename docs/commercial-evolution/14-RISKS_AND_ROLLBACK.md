# 风险与回滚

> 所属:商业级演化详细设计(阶段 0–2)。总览见 [README](README.md)。


| 风险 | 缓解 |
|---|---|
| 租户拦截改"默认拒绝"导致现有调度/消费者崩 | 先 `warn` 模式一个版本,收集缺上下文调用点,再切 `enforce`(flag) |
| 账本双写不一致 | 影子比对 + 差异告警;读切换前连续 7 天零差异 |
| 服务拆分引入分布式问题 | 业务模块不改;先拆 `worker`,再 `tracker`,最后 `rtb` |
| JWT 算法切换踩坑 | 双签发/双验证窗口(HS256 与 RS256 并存两个 TTL) |
